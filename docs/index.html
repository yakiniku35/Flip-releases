Flip 住在 Mac 的選單列。把檔案拖到圖示附近，它會長出接收區把檔案含進去，轉好的檔案放回原本的資料夾。全部用 macOS 內建的功能在你的電腦上處理，不上傳，也不用另外安裝任何套件。

PowerPoint 轉 PDF

動畫再多，PDF 也不會疊成一團。

一張投影片如果有好幾段動畫，直接匯出 PDF 時所有物件會疊在同一頁，後面出現的圖表把前面的文字蓋住。Flip 會讀取簡報裡的動畫順序，找出真的互相遮住的物件，只把那幾張投影片拆成多頁，每一頁就是按一下滑鼠後的畫面。

在設定裡選擇處理方式

  • 自動拆開會互相遮住的動畫（建議）
  • 每個動畫步驟都拆成一頁
  • 只保留每張投影片最後的畫面
  • 不處理（所有物件疊在同一頁）

簡報轉換需要安裝 Microsoft PowerPoint。

壓縮檔

先打開來看，再決定要拿哪些。

拖進 zip、7z、rar 或 tar，Flip 會打開瀏覽視窗。每個檔案都能直接預覽，勾選需要的解壓縮，或把勾選的檔案合併成一份 PDF。解壓縮和壓縮都會顯示進度。

密碼庫

有密碼的壓縮檔，自動幫你試。

打開「自動解壓縮下載的壓縮檔」後，下載的壓縮檔需要密碼時，Flip 會先試你存過的密碼，試對了就直接解開。你輸入過的密碼也會自動存起來，下次就不用再打。密碼存在 macOS 鑰匙圈，隨時能在設定裡查看和修改。

還有

合併和加密，也在同一個圖示裡。

合併

把多個檔案合成一份。在壓縮檔視窗裡，也能直接合併勾選的檔案。

  • PDF
  • Excel
  • CSV
  • Word
  • 長圖
  • 動畫 GIF
  • ZIP

加密

替檔案加上密碼再傳出去，依對方用的電腦選擇方式。

  • AES-256 ZIP
  • 相容模式 ZIP（Windows 可直接打開）
  • PDF 開啟密碼
  • 加密 DMG

常見問題

下載前你可能想知道

需要什麼環境？
macOS 14 Sonoma 或更新的版本，Apple 晶片和 Intel 的 Mac 都能用。
沒有 Office 也能轉 Word 檔嗎？
可以。Word、RTF、ODT 會用 macOS 內建的文字引擎轉換；有安裝 Microsoft Word 時會改用 Word，排版更完整。簡報需要 PowerPoint，輸出 XLS 需要 Excel。
試用結束後會怎樣？
基本的轉檔、解壓縮和壓縮都能繼續用，一次最多 5 個檔案。合併、加密、密碼庫和簡報動畫拆頁需要授權碼。
怎麼更新？
有新版本時，「設定 → 更新」會顯示出來，按一下就會下載並安裝。
介面有哪些語言？
繁體中文、English、日本語，可以在設定裡切換。
檔案會被上傳嗎？
不會。所有轉換都在你的 Mac 上完成，Flip 只有檢查更新時會連網。
