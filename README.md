# Flip

Flip is a file converter that lives in your Mac's menu bar. This repository only hosts the packaged app; the source code is not public.

## Download

1. Download the latest `Flip-<version>.zip` from [Releases](https://github.com/yakiniku35/Flip-releases/releases/latest).
2. Unzip it and drag `Flip.app` into your Applications folder.

Flip requires macOS 14 or later and runs on both Apple silicon and Intel Macs. Once installed, Flip finds new versions on its own under Settings → Updates.
