# Flip

Flip 是住在 Mac 選單列的轉檔工具。這裡是下載頁，只放打包好的 App，不含原始碼。

## 下載

1. 到 [Releases](https://github.com/yakiniku35/Flip-releases/releases/latest) 下載最新的 `Flip-版本號.zip`
2. 解壓縮後，把 `Flip.app` 拖進「應用程式」資料夾

需要 macOS 14 以上，Apple 晶片和 Intel 的 Mac 都能用。安裝後，Flip 會在「設定 → 更新」自動找到新版本。

---

Flip is a file converter that lives in your Mac's menu bar. This page only hosts the packaged app; the source code is not public. Download the latest `Flip-<version>.zip` from [Releases](https://github.com/yakiniku35/Flip-releases/releases/latest). Requires macOS 14 or later.
